# FiboSecure
FiboSecure es una página web interactiva tipo gestor de contraseñas. Permite generar contraseñas usando Fibonacci y números primos, evaluar su nivel de seguridad, guardar cuentas en una bóveda local, buscar aplicaciones y copiar o mostrar las claves guardadas. El proyecto aplica matemáticas a un problema actual: la seguridad digital.
